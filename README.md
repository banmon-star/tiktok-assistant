# TikTok LIVE Copilot · 多语言直播助理试点

一个面向真人主播的本地运行原型：把直播评论整理成待处理队列，结合当前商品资料生成简短话术，并提示保健品功效表述风险。支持巴西葡语和中东阿语／英语两组演示场景。

> 当前是作品演示版。评论来自模拟或手动输入；商品和库存都是演示数据；尚未接入 TikTok 的真实评论流，也不代表可直接投入商业直播。

## 功能

- 按购买意向、关键问题和找货需求对评论排序；主播手动选择和标记已回答。
- 根据当前市场及商品的已核实字段生成主播话术。可选用 SiliconFlow 的模型，其中包含 DeepSeek 模型选项；未配置或请求失败时使用本地规则。
- 根据关键词搜索本地商品库，显示图片、SKU、货架位置和候选结果。
- 利用浏览器支持的语音识别或手动文本检查主播话术中的预置高风险词。
- 通过 CSV 模板导入商品。导入会更新本地 `app/data/products.json`，请先备份自己的数据。

## 本地运行

需要 Python 3，无第三方 Python 依赖。

```bash
python server.py
```

Windows 可双击 `start.bat`，macOS/Linux 可运行 `sh start.sh`。浏览器打开 `http://127.0.0.1:8000`。如果 8000 端口已被占用，请先关闭占用进程。

进入“主播直播台”，点“模拟一条当前市场评论”，选择评论后生成话术；也可在“AI直播找货”中搜索演示商品。更多手动检查步骤见 [PILOT_ACCEPTANCE.md](PILOT_ACCEPTANCE.md)。

## 可选模型配置

在“AI设置”页填写自己的 SiliconFlow API Key、选择模型并点击“保存并测试”。也可设置 `SILICONFLOW_API_KEY` 环境变量；环境变量优先于界面保存的密钥。模型请求发往配置的 SiliconFlow 兼容接口，使用 `/chat/completions`，并非直接调用 DeepSeek 官方接口。

界面保存的配置位于本机用户配置目录下的 `TikTokLiveCopilot/config-siliconflow.json`，不在项目目录中。请勿将密钥或真实客户资料提交到公开仓库。模型选项反映此试点编写时的配置，具体模型是否仍可用以服务商实际接口为准。

## 数据与边界

`app/data/products.json` 中四个商品全部标记为 DEMO。导入真实商品前，应核实包装标签、适用市场和允许表述。风险扫描只覆盖预置词，不构成法律、平台规则或医疗审核；生成的话术由真人主播审核和决定是否使用。中东目标国家尚未确定，目前仅验证阿语／英语交互形式。

技术结构：Python 标准库 HTTP 服务端 `server.py`、静态前端 `app/static/index.html`、JSON 商品库。这个版本优先展示交互流程，尚未实现账户权限、数据持久化的评论队列、自动化测试或生产部署配置。
